# BoxRoute-Det：框几何监督的轻量方向路由候选

2026-10-16，Asia/Shanghai。状态：**确定进入工程最小验证的候选；尚无模型训练结果，创新性未确立。** 本方案是新研究分支，旧DetailPair保持封存。

## 1. 问题与可证伪假设

现有证据说明旧组合缺少精度—延迟收益，不能据此确认唯一根因。新问题是：在保留原生检测骨干和检测头的前提下，训练框提供的几何信息，能否让一个很小的方向路由块学到比自由选核更有用的上下文选择？

H1：正确几何监督使同结构G优于自由路由U，且优于方向交换监督W；同时G相对原生N有实际AP增量，新增推理开销受控。H0替代解释包括：收益只来自额外容量、一般多分支特征或额外训练约束，与几何对应关系无关。

这里的几何只指**轴对齐标注框宽高关系**。方形框可能包含曲线/对角缺陷，框内也有背景；它不是像素掩码、缺陷真实主方向或工业机理真值。此代理监督是否适合NEU须先读train统计，再看对照结果，不能预先认定。

## 2. 唯一结构改动

基于固定版本YOLO11n，保留原来的layer16计算，在其输出之后接一个同通道、同尺寸块。固定YAML下该处为P3/8，预计C=64、320输入时40×40；工程必须实际探测，不依赖注释硬编码。该输出同时进入Detect和后续PAN，因此可能影响P4/P5，不宣称只改变一个检测尺度。

对于输入特征 X，三个专家为：

\[
E_I=\operatorname{SiLU}(\operatorname{BN}(\operatorname{DWConv}_{3\times3}(X))),\quad
E_H=\operatorname{SiLU}(\operatorname{BN}(\operatorname{DWConv}_{1\times7}(X))),\quad
E_V=\operatorname{SiLU}(\operatorname{BN}(\operatorname{DWConv}_{7\times1}(X))).
\]

三路DWConv均stride1、对称same padding、groups=C、bias=False。路由为每个位置共享于通道的三维概率：

\[
\alpha(X)=\operatorname{softmax}_{I,H,V}(W_r*X+b_r),\qquad
Y=X+\gamma\,\operatorname{BN}\left(P\left(\alpha_IE_I+\alpha_HE_H+\alpha_VE_V\right)\right).
\]

W_r为C→3的1×1卷积（含bias），P为C→C的1×1卷积（bias=False，无末端激活），γ为可训练标量。路由卷积的weight/bias置0，初始α为1/3；γ初始0，末端BN保持正常γ=1/β=0。三个候选条件U/G/W具有完全相同的参数和初始state。

**必须始终计算分支，不能因γ当前为0而跳过。** 初始Y=X只保证函数初始化不扰动共同预训练模型，不意味着零计算开销。推理保留softmax与路由，不能把输入依赖权重声称为可静态融合或免费。仅常规Conv-BN可融合。

## 3. 训练框如何监督路由

取增强、裁剪及letterbox后，原生loss实际接收的每个有效框b，其宽高w_b,h_b均为正。定义：

\[
q_b=\frac{1}{w_b+h_b}\left(2\min(w_b,h_b),\ [w_b-h_b]_+,\ [h_b-w_b]_+\right),
\]

维度顺序始终为(I,H,V)。它是研究者设定的连续混合目标，不是已有最优路由结论。例如1:1对应(1,0,0)，7:1对应(.25,.75,0)，1:7对应(.25,0,.75)。不按类别名手工指定横/竖，不加预测角度、分割头或新数据标注。

在P3格点中心落入框b的集合R_b上平均路由概率，而非对每个框内点强迫相同方向：

\[
\bar\alpha_b=|R_b|^{-1}\sum_{u\in R_b}\alpha(u),\qquad
\tilde\alpha_b=\frac{\bar\alpha_b+\epsilon\mathbf1}{1+3\epsilon},\quad \epsilon=10^{-6}.
\]

格点采用left/top inclusive、right/bottom exclusive规则。细框若不含格点中心，以框中心最近的合法格点作回退并记数。框重叠时逐实例分别计算，不先合并框；报告重叠与回退比例。不额外用背景伪标签强制路由，也不把框内全部当缺陷分割真值。

每图先对框平均，再对batch平均；空框图该项为0：

\[
L_{route}=\frac1B\sum_{i=1}^{B}\frac{1}{\max(N_i,1)}\sum_{b\in i}
\operatorname{KL}(q_b\Vert\tilde\alpha_b).
\]

正确求和q=0项为0，使用FP32稳定的log/KL实现。q来自标签，不参与求导。

固定版原生criterion已经按B缩放，故总标量为：

\[
L_{total}=\sum L_{native}+B\lambda(e)L_{route},\qquad
\lambda(e)=0.05\min\left(1,\frac{e+1}{5}\right),
\]

e为从0计数的epoch。保留原生BCE/CIoU/DFL、TaskAlignedAssigner与检测头。U的λ恒0；G用正确q；W使用q'=(q_I,q_V,q_H)，其熵和各框约束强度相同，交换方向对应关系。W是负对照，不能因其结果不好而当真实方案性能。

训练为**单视图**。不沿用旧双视图、Haar幅值、一致性、FFT或teacher。几何辅助仅在训练使用；推理只读取图像，GT和宽高目标生成器不得出现在推理签名中。

α的大小也不等于专家的实际语义贡献：专家输出幅值、P及γ可以补偿权重变化。需同时记录专家输出范数、加权输出范数、γ与分组AP；不能只凭路由贴近q就宣称机制有效。

## 4. 已有理论、已跑数值与未跑实证

**解析事实。** w,h>0时，q三项非负且和为1：例如w≥h时，2h+(w−h)=w+h；另一种情形同理。共同缩放宽高不改变q；交换宽高只交换H/V。概率归一化下KL非负。γ=0时Y=X，但只要分支照常计算，计算量仍存在。以上均不证明检测提升、真实方向恢复或收敛到有用路由。

**实际NumPy检查。** 10000个宽高对的单纯形/缩放/交换检查通过；4种非法输入被拒绝；128个单位置KL和32个四格ROI平均KL有限差分通过，最大梯度误差分别约4.91e−11、2.60e−11。实现和原始输出见check_design_math.py与checks。它们不是PyTorch自动微分、完整网络或真实数据验证。首次AST检查误将dict(...)当literal，修正后通过；原失败日志与脚本保留。

**设计开销估算。** C=64时新增可训练参数6276；40×40处卷积MAC为9,216,000。计数包含三DW/BN、router、PW/BN和γ，MAC只计卷积，未计BN、SiLU、softmax、乘加、内存访问或kernel launch。不是整网实测FLOPs，也不推出GPU延迟小于5%。

**尚未执行。** 完整PyTorch前向/损失/梯度等价，初始化映射、NEU读取、真实训练、CUDA/Windows、GPU延迟、各类召回改善与多种子，全部待下一工程。没有性能提升或创新性成立的实证。
